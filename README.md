2. Распакуйте архив на компьютере.
3. Откройте страницу расширений:

### ⚓ About

**OS G Chat Bridge** helps you preserve long ChatGPT conversations without manually copying thousands of messages.

Your ideas, research, code, and conversation history are worth keeping.

The extension is part of **OS G — The Flying Dutchman**, a project exploring long-term AI memory and local artificial intelligence.

- ⏸️ Pause and resume.
- 🖥️ Background scanning.
- 🌍 Russian and English interface.
- ❤️ Free to use, without mandatory donations.

**Browsers:** Brave, Google Chrome, Microsoft Edge.

### 🛠️ Installation

1. Download the ZIP archive.
2. Extract it to a folder.
3. Open your browser's extensions page:
   - Brave: `brave://extensions`
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
4. Enable **Developer Mode**.
5. Click **Load unpacked**.
6. Select the `osg-chat-bridge` folder containing `manifest.json`.

### 📖 How to use

1. Open a ChatGPT conversation.
2. Scroll to the point where you want to begin collection.
3. Start scanning with OS G Chat Bridge.
4. Adjust scanning speed if needed.
5. Click **Verify** after scanning.
6. Save the conversation as ZIP, TXT or PDF.

### ⚠️ Known limitations

- Images are not included in exports yet.
- Some emoji may render incorrectly in PDF.
- Zero detected gaps does not guarantee complete conversation coverage.
- Changes to the ChatGPT interface may require updates.
